# Shyna Caller Guard 2.0 Premium

Major additions over v1.5:
- Real draggable swipe left/right incoming-call control with haptic feedback.
- Contact photo loading from the system Contacts provider, with safe avatar fallback.
- Caller information settings now control name, number and SIM display.
- Call background selection now changes the real call-screen background.
- Volume-up answer setting now handles the physical volume-up key while ringing.
- Advanced automatic recording scopes: all, incoming, outgoing, unknown, or selected numbers.
- Separate do-not-record and record-only-selected number lists.
- Existing quick responses, dual-SIM selection, T9 search, call filters and rule engine retained.
- App version updated to 2.0 / versionCode 20.

Platform notes:
- Two-way call recording, video upgrade, conference merge and Bluetooth routing remain dependent on Android, device and carrier support.
- Live Truecaller database access is not included because it requires an official Truecaller partnership/API.
- Full screen is the reliable default call UI. OEM-specific floating call bubbles/popups require additional overlay and background-execution testing per manufacturer.
