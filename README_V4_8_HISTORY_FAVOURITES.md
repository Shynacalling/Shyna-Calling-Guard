# Shyna Caller Guard v4.8

- Samsung-style per-number call history grouped by date.
- Call duration and SIM badge for every history entry.
- Closest matching call recording can be played directly from the history row.
- Fixed bottom actions: Favourite, Share, Block and Delete.
- App favourites appear in a horizontal section at the top of Contacts.
- Favourite cards automatically become compact when the list grows.
- Call-log delete confirmation and dual-SIM block rule creation.
