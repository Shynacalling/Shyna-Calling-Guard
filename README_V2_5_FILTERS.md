# Shyna Caller Guard Premium v2.5

## Advanced call filters
- Single-select tick for All SIMs, SIM 1, or SIM 2.
- Single-select tick for All, Missed, Rejected, Outgoing, Incoming, or Blocked calls.
- Only the selected SIM + call type combination is displayed.
- Blocked calls are excluded from the normal All calls list and appear only under Blocked.
- Top quick chips: All, Missed, Blocked, Filters.
