# Shyna Caller Guard Premium v2.6

Dialer flow refinement based on the supplied Samsung-style reference:

- Minimal keypad top action row: Add contact, Rules, Search, More.
- Number appears in a centered large display as soon as the first key is pressed.
- Keypad recents disappear immediately after typing starts.
- Only the best matching saved contact name appears below the number.
- Backspace remains enabled until the final typed character is removed.
- Video, audio-call and backspace actions use the reference placement.
- SIM selector stays directly below the call controls and remembers the chosen mode.
- Video call requests use Android Telecom video-state extras and the selected SIM when supported.
- Search from the keypad opens the in-app synced contact search.
- Existing rules, filters, blocked list, recording, contact sync, CSV and voice features are preserved.
