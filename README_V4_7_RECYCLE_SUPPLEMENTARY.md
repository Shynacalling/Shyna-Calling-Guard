# Shyna Caller Guard v4.7

## Recycle bin
- Deleted blocked-number and SIM rules are moved to an app recycle bin.
- Restore and permanent delete actions.
- Items are purged after 30 days when the repository/recycle screen is accessed.
- Empty recycle bin action with confirmation.

## Supplementary services
- In-app Samsung-style dual-SIM overview.
- Caller ID, call forwarding, call barring, call waiting and fixed dialling number rows.
- Each row safely resolves Samsung/Android carrier settings intents with fallbacks.
- Actual values and availability remain carrier/firmware controlled.
