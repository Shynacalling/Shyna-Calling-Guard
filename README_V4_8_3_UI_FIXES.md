# v4.8.3 UI and action fixes

- Added Recycle bin as the third item in the top overflow menu beside Block & SIM rules and Call settings.
- Removed the visible Wi-Fi Calling entries from Call settings and Feature Hub.
- Replaced the unreliable duplicate-contact shortcut with an in-app review dialog and merge action using Android Contacts aggregation APIs, plus a safe Contacts-app fallback.
- Replaced the inline in-call DTMF keypad with a fixed dialog keypad. Entered digits remain inside the keypad panel and each key sends a DTMF tone to the active Telecom call.
