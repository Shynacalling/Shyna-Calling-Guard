# Shyna Caller Guard Premium v4.6

- Custom call background via Android document picker with persisted read access.
- Aurora purple, AMOLED black, Minimal blue, Custom image, and reset option.
- Add Call chooser for dialer or phone contacts.
- Merge button becomes available when Telecom marks calls conferenceable.
- Conference participants panel supports add more, disconnect individual participant, and end conference.
- Existing mute, speaker, Bluetooth, keypad, hold, and recording controls remain available.
- Conference capacity and video/conference availability remain carrier dependent.
